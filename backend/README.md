# Backend Developer Guide

This directory holds the backend codebase for the FoodShareHackathon.

## Setup & Development
The backend developer will implement the authentication server, posts storage, leaderboard computation, and claim state machine here.

### Planned Endpoints
- `POST /api/auth/login`
- `POST /api/auth/register`
- `GET /api/posts`
- `POST /api/posts`
- `POST /api/posts/claim`
- `GET /api/leaderboard`
