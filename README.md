# FoodShareHackathon

FoodShareHackathon is a modern, web-based food sharing platform connecting restaurants with local shelters to redistribute surplus food and minimize waste.

## Project Structure

This repository is structured as a multi-module workspace:

- **`shared/`**: Contains common typescript interfaces, endpoints, constants, and date formatting utilities shared across components.
- **`web/`**: The frontend React web application, utilizing React Router v6 and custom state hooks.
- **`backend/`**: Folder for the backend database and API codebase (placeholder).
- **`ai/`**: Folder for AI waste-prediction logic and APIs (placeholder).

## Quick Start (Web App)

1. Navigate to the web folder:
   ```bash
   cd web
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm start
   ```
